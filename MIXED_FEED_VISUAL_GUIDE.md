## 📊 Analytics Tracking Flow

### View Tracking

```
User Scrolls Feed
       ↓
Post Enters Viewport (Intersection Observer)
       ↓
Frontend Triggers Event
       ↓
POST /api/v1/posts/{postId}/interactions/view
{
  "action": "view",
  "source": "feed",
  "deviceType": "mobile"
}
       ↓
Backend Increments views++
       ↓
Database Updated
       ↓
Response: { "newCount": 12501 }
```

### Click Tracking

```
User Clicks Post
       ↓
Frontend Captures Click Event
       ↓
POST /api/v1/posts/{postId}/interactions/click
{
  "action": "click",
  "source": "feed",
  "deviceType": "mobile"
}
       ↓
Backend Increments clicks++
       ↓
Database Updated
       ↓
Navigate to Detail Page
```

### Share Tracking

```
User Clicks Share Button
       ↓
Share Dialog Opens
       ↓
User Confirms Share
       ↓
POST /api/v1/posts/{postId}/interactions/share
{
  "action": "share",
  "source": "detail",
  "deviceType": "desktop"
}
       ↓
Backend Increments shares++
       ↓
Database Updated
       ↓
Share to Social Media
```

## 🔄 Complete User Journey

### Journey 1: Browsing Homepage

```
1. User Opens App
   ↓
2. Load Mixed Feed
   GET /api/v1/posts/feed?pageNumber=1&pageSize=20&marketingRatio=4
   ↓
3. Feed Displays:
   - 16 Community Posts
   - 4 Marketing Posts (mixed in)
   ↓
4. User Scrolls
   - View tracking fires for each post
   POST /api/v1/posts/{postId}/interactions/view
   ↓
5. User Clicks Marketing Post
   - Click tracking fires
   POST /api/v1/posts/{postId}/interactions/click
   ↓
6. Navigate to Product Page
   - Load related posts
   GET /api/v1/posts/related/{productId}
   ↓
7. User Shares Post
   - Share tracking fires
   POST /api/v1/posts/{postId}/interactions/share
```

### Journey 2: Product Discovery

```
1. User Searches for "iPhone"
   ↓
2. Views Product Detail Page
   ↓
3. Load Related Posts
   GET /api/v1/posts/related/{productId}
   ↓
4. See Marketing Posts:
   - "Giảm 20% khi mua kèm AirPods"
   - "Trả góp 0% lãi suất"
   ↓
5. See Community Reviews:
   - "Vừa mua iPhone 15, rất hài lòng!"
   - "Review chi tiết về iPhone 15 Pro Max"
   ↓
6. User Clicks Promotion
   - Click tracking fires
   - Navigate to checkout
```

## 🎯 Summary

Mixed Feed API cung cấp trải nghiệm người dùng tối ưu với:

✅ **Balanced Content**: Kết hợp organic và marketing content  
✅ **Smart Distribution**: Marketing posts xuất hiện đều đặn  
✅ **Priority Control**: Admin kiểm soát độ ưu tiên hiển thị  
✅ **Location Targeting**: Hiển thị đúng vị trí, đúng context  
✅ **Analytics Tracking**: Đo lường hiệu quả real-time  
✅ **Responsive Design**: Tối ưu cho cả mobile và desktop  
✅ **User-Friendly**: Không làm phiền user experience

**Recommended Configuration**:
- Marketing Ratio: 4 (20% marketing, 80% community)
- Priority Score: 50-95 (depending on importance)
- Page Size: 20 items (mobile), 30 items (desktop)
- Auto-Featured: Priority > 80

Hệ thống đã sẵn sàng để triển khai! 🚀
